# คูปอง/โปรโมชัน

เมนู **การขาย → คูปอง/โปรโมชัน** (`/coupons`, `CouponController`, `resources/views/pages/coupons/*`)

ส่วนลดทุกแบบใช้คูปอง นักเรียนกรอกรหัสตอนสั่งซื้อ ระบบตรวจเงื่อนไขทั้งหมดแล้วหักส่วนลด (`App\Support\CouponService`)

เมนูโปรโมชันเดิมรวมเข้ามาที่นี่แล้ว `/promotions` redirect มาที่ `/coupons` ตาราง `promotions*` และ model `Promotion` ยังอยู่แต่ไม่มีหน้าใช้งาน

## ฟอร์ม

| กลุ่ม | ฟิลด์ | เก็บที่ |
|------|------|------|
| ข้อมูลคูปอง | รหัส (A–Z ตัวเลข `_` `-` เก็บเป็นตัวพิมพ์ใหญ่), สถานะ, รายละเอียด | `coupons` |
| ส่วนลด จำนวนครั้ง ระยะเวลา | ประเภท (% / บาท), มูลค่า, ส่วนลดสูงสุด, ยอดขั้นต่ำ, ใช้ได้ทั้งหมด, ต่อคน, วันเริ่ม, วันสิ้นสุด | `coupons` |
| ใครใช้ได้ | กลุ่มนักเรียน | `coupons.student_group` (`all` / `new` / `returning`) |
| | ประเภทการซื้อ: ทุกการซื้อ / ซื้อใหม่เท่านั้น / ต่ออายุเท่านั้น | `coupons.purchase_type` (`any` / `new` / `renewal`) |
| | ต้องเคยซื้อวิชา / หนังสือ | `coupon_required_courses`, `coupon_required_products` |
| | ต้องดูวิดีโอ, ต้องดูอย่างน้อย (นาที ทศนิยมทีละ 0.5) | `coupon_required_videos`, `coupons.required_video_seconds` |
| ของแถม | เมื่อซื้อวิชา, แถมข้อสอบ, แถมหนังสือ | `coupon_gift_courses`, `coupon_gift_assessments`, `coupon_gift_products` |
| สินค้าที่ใช้ส่วนลดได้ | วิชา หลักสูตร ข้อสอบขายแยก หนังสือ | `coupon_courses`, `coupon_curriculums`, `coupon_assessments`, `coupon_products` |

ช่องเลือกหลายรายการใช้ `x-form.item-picker` (modal มีค้นหาและเลือกทั้งหมด)

ใน modal "ต้องดูวิดีโอก่อนใช้คูปอง" คลิปทดลองเรียน (`videos.is_free`) อยู่บนสุด มีป้าย "ทดลองเรียน · ดูได้ x นาที" (จาก `trial_seconds` ถ้าไม่จำกัดเป็น "ทั้งคลิป") ป้ายสีเขียวเมื่อมีวิชาที่คลิปนี้อยู่เปิดทดลองเรียน (`courses.is_trial_available`) ถ้ายังไม่มีวิชาไหนเปิด ป้ายเป็นสีเทาและต่อท้าย "(วิชายังไม่เปิดทดลอง)" พิมพ์ "ทดลอง" ในช่องค้นหาเพื่อกรองได้

คนที่ยังไม่ซื้อวิชาดูได้เฉพาะคลิปทดลองและไม่เกินเวลาทดลอง ระบบไม่ตั้งว่าดูจบให้ผู้ทดลองที่ถูกจำกัดเวลา ถ้าคูปองเลือกคลิปทดลองที่จำกัดเวลาโดยไม่กำหนดนาที (ต้องดูจนจบ) หรือกำหนดนาทีเกินเวลาทดลอง ผู้ที่ยังไม่ซื้อจะไม่ผ่านเงื่อนไขนี้

มูลค่าส่วนลดเว้นว่างหรือ 0 ได้ เพื่อทำคูปองแถมอย่างเดียว แต่ต้องเลือกข้อสอบหรือหนังสือแถมอย่างน้อย 1 รายการ หน้าแสดงส่วนลดเป็น "ไม่มีส่วนลด (แถมอย่างเดียว)"

ระบบไม่ให้บันทึกในกรณีต่อไปนี้

- ไม่มีทั้งส่วนลดและของแถม

- กำหนดนาทีที่ต้องดูโดยไม่เลือกวิดีโอ
- กำหนดนาทีเกินความยาวของวิดีโอที่เลือก
- เลือก "เมื่อซื้อวิชา" แต่ไม่เลือกข้อสอบหรือหนังสือที่จะแถม

## การตรวจตอนกรอกรหัส

ตรวจตอนคิดยอด (`POST /checkout/quote`, `POST /guest/checkout/quote`) และตอนสร้างออเดอร์ทุกช่องทาง (หน้าเว็บ, guest, แอดมินสร้างให้นักเรียน, ออเดอร์หนังสือในหลังบ้าน) ไม่ผ่านตอบ `422` ที่ `coupon_code`

| ลำดับ | เงื่อนไข | ข้อความเมื่อไม่ผ่าน |
|------|------|------|
| 1 | สถานะเปิดใช้งาน และอยู่ในช่วงวันเริ่มถึงวันสิ้นสุด | คูปองนี้ปิดใช้งาน / ไม่อยู่ในช่วงเวลาที่ใช้ได้ |
| 2 | จำนวนครั้งทั้งหมด และต่อคน (นับเฉพาะออเดอร์ที่ชำระแล้ว) | ถูกใช้ครบจำนวนแล้ว |
| 3 | กลุ่มนักเรียน: ใหม่ = ยังไม่มีออเดอร์ที่ชำระแล้ว, เก่า = มีอย่างน้อย 1 ใบ | ใช้ได้เฉพาะนักเรียนใหม่ / นักเรียนที่เคยซื้อแล้ว |
| 4 | ต้องเคยซื้อ **อย่างน้อย 1 รายการ** จากที่เลือก: มีออเดอร์ที่ชำระแล้วที่มีวิชาหรือหนังสือนั้น หรือมีสิทธิ์เรียนวิชานั้น (`enrollments` รวมสิทธิ์จากหลักสูตรหรือแอดมินเพิ่ม) | คูปองนี้ใช้ได้เมื่อเคยซื้อ ... มาก่อน |
| 5 | ต้องดู **ทุกคลิป** ที่เลือก: `video_progress.completed_at` มีค่า (ดูถึง 90%) หรือถ้ากำหนดนาที `position_seconds` ต้องไม่น้อยกว่าเวลานั้น (ไม่เกินความยาวคลิป) | ต้องดูวิดีโอ ... ก่อนใช้คูปองนี้ |
| 6 | ประเภทการซื้อ: กรองรายการก่อนคิดส่วนลด (ดูด้านล่าง) | ใช้ได้เฉพาะการต่ออายุ ... / ใช้ได้เฉพาะการซื้อใหม่ ... |
| 7 | มีรายการที่ใช้ส่วนลดได้ และถึงยอดขั้นต่ำ | ใช้กับรายการในออเดอร์ไม่ได้ / ยอดต้องอย่างน้อย ... |
| 8 | คูปองแถมอย่างเดียว (ส่วนลด 0): ออเดอร์ต้องได้ของแถมจริง เช่น มีวิชาที่ทำให้ได้ของแถม | ออเดอร์นี้ยังไม่ได้รับของแถมจากคูปองนี้ |

ประเภทการซื้อ (`CouponService::filterByPurchaseType()`)

- **ต่ออายุ:** ผู้ใช้เคยมีสิทธิ์เรียนรายการนั้นมาก่อน คือมีแถวใน `enrollments` ของวิชา หลักสูตร หรือข้อสอบนั้น
  - นับทุกสถานะ ทั้งยังใช้ได้ หมดอายุ และยกเลิก
  - นับสิทธิ์ที่ได้จากหลักสูตร ของแถม และแอดมินเพิ่มให้
  - ไม่จำกัดช่วงเวลา
- **ซื้อใหม่:** ยังไม่เคยมีสิทธิ์รายการนั้น หนังสือไม่มีการต่ออายุ จึงนับเป็นซื้อใหม่เสมอ
- **ส่วนลดคิดเฉพาะรายการที่ตรงประเภท:** เช่น ตะกร้ามีวิชาที่ต่ออายุ 1 วิชาและวิชาใหม่ 1 วิชา คูปองต่ออายุจะลดเฉพาะวิชาที่ต่ออายุ ยอดขั้นต่ำก็คิดจากรายการที่ตรงประเภทเท่านั้น
- **ลูกค้าแบบ guest:** อีเมลที่ยังไม่มีบัญชีใช้คูปองต่ออายุไม่ได้

## คูปองที่ใส่ให้อัตโนมัติ

เมื่อลูกค้าไม่ได้กรอกโค้ด หน้าเว็บคิดยอดด้วย `auto_coupon` แล้วระบบหาคูปองให้เอง (`CouponService::bestAutomatic()`)

- **ใบที่หาให้:** สถานะเปิดใช้งาน และเป็นแบบใดแบบหนึ่ง
  - ประเภทการซื้อ "ต่ออายุเท่านั้น"
  - มีของแถม "เมื่อซื้อวิชา" (ออเดอร์ต้องมีวิชานั้น) คูปองแบบนี้ตั้งส่วนลด 0 ได้ เป็นโปรโมชันแถมอย่างเดียว
- **ต้องผ่านเงื่อนไขทั้งหมด** เหมือนกรอกโค้ดเอง ใบที่ไม่ผ่านถูกข้ามโดยไม่แจ้ง error
- **หลายใบผ่าน:** เลือกใบที่ลดมากที่สุด ถ้าเท่ากันเลือกใบที่มีของแถมมากกว่า ออเดอร์หนึ่งใช้ได้คูปองเดียว ถ้าตะกร้าเข้าได้ทั้งส่วนลดต่ออายุและโปรโมชันแถม ลูกค้าได้แค่ใบเดียว
- **ลูกค้าเห็นรหัส** บนหน้าเว็บ จึงไม่ควรตั้งคูปองที่ต้องการเก็บเป็นความลับเป็นแบบต่ออายุหรือแถมเมื่อซื้อวิชา
- **ลูกค้ากดไม่ใช้** หน้าเว็บจะไม่ใส่ให้อีก และกรอกโค้ดอื่นแทนได้

ลูกค้าแบบ guest ที่อีเมลยังไม่มีบัญชี ถือเป็นนักเรียนใหม่ที่ยังไม่เคยซื้อและยังไม่เคยดูวิดีโอ

`position_seconds` คือตำแหน่งล่าสุดที่เล่น ไม่ใช่ตำแหน่งไกลสุด ถ้านักเรียนเลื่อนกลับไปต้นคลิป ค่านี้จะลดลง แต่ `completed_at` ไม่หาย

## ส่วนลดและการนับครั้ง

ส่วนลดถูกล็อกไว้ที่ `orders.discount_amount` ตอนสร้างออเดอร์

- **การนับครั้ง:** บันทึกที่ `coupon_usages` และ `coupons.usage_count` เมื่อชำระแล้วเท่านั้น (`CouponService::commit()`)
- **ไม่ตรวจซ้ำตอนชำระ:** ถ้าคูปองถูกปิด หมดอายุ แก้ค่า หรือใช้ครบระหว่างรอชำระ ออเดอร์ยังชำระได้ด้วยส่วนลดเดิม
- **ใช้เกินจำนวน:** ถ้าเกิน `usage_limit` เพราะมีหลายออเดอร์ค้างชำระพร้อมกัน ระบบบันทึกตามจริงและเขียน warning ลง log
- **ยกเลิกออเดอร์ที่ยังไม่ชำระ:** คืนสิทธิ์คูปอง (`release()`)

## ของแถม

ให้ครั้งเดียวต่อออเดอร์หลังชำระสำเร็จ (`StudentPurchase::grantCouponGifts()`, กันซ้ำด้วย `coupon_usages.gifts_granted_at`)

- **เงื่อนไขการได้ของแถม:** ถ้าเลือก "เมื่อซื้อวิชา" ออเดอร์ต้องมีวิชานั้นอย่างน้อย 1 วิชา ถ้าไม่เลือก ทุกออเดอร์ที่ใช้คูปองได้ของแถม
- **ข้อสอบแถม:** เปิดสิทธิ์ใน `enrollments` ด้วย `source = coupon_gift` และ `order_id` ของออเดอร์ที่ซื้อ หน้านักเรียนแสดงว่า "ของแถมจากคูปอง"
  - ระยะเวลาเท่ากับรายการที่ทำให้ได้ของแถม (วิชาที่เลือก หรือทุกรายการในออเดอร์ถ้าไม่ได้เลือกวิชา)
  - ถ้ามีหลายรายการ ใช้ระยะที่ยาวที่สุด ถ้ามีรายการที่ไม่จำกัดเวลา ข้อสอบแถมก็ไม่จำกัดเวลา
- **หนังสือแถม:** สร้างออเดอร์หนังสือใหม่ยอด 0 บาท สถานะชำระแล้ว / กำลังจัดเตรียม / รอจัดส่ง
  - `orders.gift_for_order_id` ชี้ไปที่ออเดอร์ต้นทาง และหมายเหตุ "ของแถมจากคูปอง ... ของออเดอร์ ..."
  - **ที่อยู่จัดส่ง:** ถ้าออเดอร์ต้นทางเป็นออเดอร์หนังสือ ใช้ที่อยู่ของออเดอร์นั้น ไม่เช่นนั้นใช้ที่อยู่ในโปรไฟล์นักเรียน แอดมินแก้ได้ในหน้าออเดอร์
  - ขึ้นในเมนูออเดอร์หนังสือพร้อมป้าย "ของแถมจากคูปอง" และนับใน badge ออเดอร์ที่กำลังดำเนินการ ไม่มีรายการชำระเงินและใบเสร็จ
- **จังหวะที่ให้ของแถม:**
  - QR / บัตร / แอดมินอนุมัติสลิป / ออเดอร์ยอด 0 (`review()`)
  - แอดมินบันทึกชำระในหน้านักเรียน (`pay()`)
  - แอดมินตั้งออเดอร์หนังสือเป็นชำระแล้วในหน้าแก้ไขออเดอร์
- **ยกเลิกหรือคืนเงินภายหลัง:** ไม่ดึงของแถมคืนอัตโนมัติ

## API

- `coupon.gifts` ในผล `POST /checkout/quote` และ `POST /guest/checkout/quote` บอกของแถมที่ออเดอร์นี้จะได้ ดู `docs/student-api.md`
- ไม่มี endpoint สำหรับดูรายการคูปอง นักเรียนต้องรู้รหัสเอง
