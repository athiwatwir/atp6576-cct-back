# แดชบอร์ด

หน้าแรกของหลังบ้าน (`/`, `resources/views/pages/dashboard/ecommerce.blade.php`) โหลดข้อมูลจาก `GET /dashboard/summary` (`DashboardController::summary()`) ผลแคช 45 วินาทีต่อช่วงวันที่

## ตัวกรองวันที่

- ปุ่มลัด: วันนี้, 7 วัน, 30 วัน, เดือนนี้ (ค่าเริ่มต้น), เดือนที่แล้ว, ปีนี้ หรือเลือกวันเริ่มถึงวันสิ้นสุดเองแล้วกด "ดูข้อมูล"
- ส่ง `from` และ `to` แบบ `Y-m-d` เป็นวันตามเวลาไทย (Asia/Bangkok) ระบบแปลงเป็น UTC ก่อนค้นในฐานข้อมูล วันสิ้นสุดเกินวันนี้ถูกตัดเป็นวันนี้
- ช่วงวันที่อยู่ใน URL (`/?from=2026-10-01&to=2026-10-31`) รีเฟรชหรือส่งลิงก์ต่อได้
- เลือกได้ไม่เกิน 3 ปี วันเริ่มหลังวันสิ้นสุดตอบ `422`

## ข้อมูลที่ใช้ช่วงวันที่

| ส่วน | คิดจาก |
|------|------|
| รายได้ | ยอดออเดอร์ที่ชำระแล้ว (`orders.paid_at` อยู่ในช่วง) เทียบเปอร์เซ็นต์กับช่วงก่อนหน้าที่ยาวเท่ากัน |
| นักเรียนใหม่ | บัญชีนักเรียนที่สร้างในช่วง เทียบกับช่วงก่อนหน้า |
| กราฟรายได้ | รายวันตามวันที่ไทย ถ้าช่วงยาวกว่า 62 วันรวมเป็นรายเดือน |
| รายได้ตามประเภท | รายการในออเดอร์ที่ชำระในช่วง แยกวิชา หลักสูตร ข้อสอบ หนังสือ |
| ออเดอร์ล่าสุดในช่วงนี้ | ออเดอร์ที่สร้างในช่วง (จำนวนทั้งหมด และ 8 รายการล่าสุด) ปุ่ม "ดูข้อมูล" เปิดหน้ารายละเอียดตามชนิด (`Order::adminUrl()`) ปุ่ม "ปริ้นใบเสร็จ" เปิด PDF ในแท็บใหม่ (`orders.receipt?inline=1`, `receipt_url` ใน summary) กดได้เฉพาะออเดอร์ที่ชำระแล้ว |

"กำลังเรียน" (สิทธิ์ที่ใช้งานอยู่) และ "รอตรวจสอบ" (สลิปรอตรวจ) เป็นตัวเลขปัจจุบัน ไม่ขึ้นกับช่วงวันที่

# แดชบอร์ดการเรียน

เมนู **ภาพรวม → แดชบอร์ดการเรียน** (`/learning-dashboard`, `LearningDashboardController`, `resources/views/pages/learning-dashboard/index.blade.php`) ดูนักเรียนรายวิชา สิทธิ์ใกล้หมดอายุ และความคืบหน้าของแต่ละคน

ข้อมูลมาจากสิทธิ์เรียนรายวิชา (`enrollments` ที่มี `course_id`, สถานะ `active`, ผู้ใช้เป็นนักเรียน) รวมสิทธิ์ที่ได้จากการซื้อหลักสูตรด้วย ไม่รวมสิทธิ์ข้อสอบขายแยก

| สถานะ | เงื่อนไข |
|------|------|
| กำลังเรียน | ไม่มีวันหมดอายุ หรือยังไม่ถึงวันหมดอายุ |
| ใกล้หมดอายุ | หมดอายุภายใน 7 / 14 / 30 วัน (เลือกที่มุมขวาบน `?soon=`) |
| หมดอายุแล้ว | หมดอายุภายใน 30 วันที่ผ่านมา (เก่ากว่านั้นไม่แสดง) |

**ความคืบหน้า** = วิดีโอของวิชาที่นักเรียนดูจบ (`video_progress.completed_at` ระบบตั้งเมื่อดูถึง 90%) ÷ วิดีโอทั้งหมดของวิชาตอนนี้ (ไม่นับบทหรือวิดีโอที่ลบแล้ว) คำนวณสดทุกครั้ง ไม่ใช้ `learning_progress` ที่บันทึกไว้ เพราะค่านั้นไม่อัปเดตเมื่อแอดมินเพิ่มหรือลบวิดีโอ วิชาที่ยังไม่มีวิดีโอแสดง `-` "เรียนล่าสุด" มาจาก `video_progress.last_watched_at`

ส่วนในหน้า:

- การ์ดสรุป: นักเรียนที่กำลังเรียน (คนและสิทธิ์), ออนไลน์ตอนนี้ (และจำนวนที่กำลังดูวิดีโอ อัปเดตเองทุก 30 วินาที), ใกล้หมดอายุ, หมดอายุแล้ว, ความคืบหน้าเฉลี่ย (และจำนวนที่ยังไม่เริ่ม), เรียนจบ 100% กดการ์ดเพื่อกรองรายการด้านล่าง
- ออนไลน์ตอนนี้: วิชาที่มีคนกำลังดูวิดีโอพร้อมจำนวนคน และรายชื่อนักเรียนออนไลน์ (สูงสุด 50 คน คนที่กำลังดูวิดีโอขึ้นก่อน แสดงวิชาและชื่อคลิปล่าสุด) ดูวิธีนับด้านล่าง
- รายวิชา: นักเรียน, ใกล้หมดอายุ, ความคืบหน้าเฉลี่ย, เรียนจบ, ยังไม่เริ่ม กดชื่อวิชาเพื่อดูรายชื่อ
- นักเรียนรายวิชา: ค้นหาชื่อ/อีเมล, กรองวิชา, สถานะ, เรียงตามหมดอายุก่อน (ค่าเริ่มต้น) / ความคืบหน้า / เรียนล่าสุด / ชื่อ หน้าละ 25 รายการ แต่ละแถวแสดงรูปโปรไฟล์ (`users.avatar` ถ้าไม่มีแสดงอักษรแรกของชื่อ เหมือนรายชื่อออนไลน์) ความคืบหน้า (ดูจบ x/y วิดีโอ) วันเริ่มเรียน วันหมดอายุ และจำนวนวันที่เหลือ

## ออนไลน์ตอนนี้

ระบบไม่มี heartbeat แยก ใช้ร่องรอยที่มีอยู่ภายใน 5 นาทีล่าสุด (`LearningDashboardController::ONLINE_MINUTES`) นับเฉพาะผู้ใช้ที่เป็นนักเรียน

| ค่า | คิดจาก |
|------|------|
| ออนไลน์ | เรียก API ด้วย token ที่ล็อกอินอยู่ (`personal_access_tokens.last_used_at` ที่ Sanctum อัปเดตทุกคำขอ) หรือบันทึกความคืบหน้าวิดีโอในช่วงนั้น |
| กำลังดูวิดีโอ / วิชา | `learning_progress.last_activity_at` ล่าสุดของนักเรียน (อัปเดตทุกครั้งที่เว็บนักเรียนเรียก `PUT /courses/{slug}/videos/{video}/progress`) ชื่อคลิปมาจาก `video_progress.last_watched_at` ล่าสุด |

ข้อจำกัด: นักเรียนที่เปิดหน้าเว็บค้างไว้โดยไม่มีคำขอ API เกิน 5 นาทีจะไม่นับว่าออนไลน์ ผู้ที่ไม่ได้ล็อกอินไม่นับ ความแม่นของ "กำลังดูวิดีโอ" ขึ้นกับความถี่ที่เว็บนักเรียนส่งความคืบหน้าระหว่างเล่น (ควรส่งถี่กว่า 5 นาที)

หน้าเว็บดึงข้อมูลใหม่จาก `GET /learning-dashboard/online` (JSON, `learning-dashboard.online`) ทุก 30 วินาทีเมื่อแท็บเปิดอยู่ และกดปุ่ม "รีเฟรช" ได้
