# การเงิน (Finance Overview)

หน้ารวมยอดการเงินทั้งระบบอยู่ที่ **การขาย → การเงิน** (`/finance`)

## สิ่งที่แสดง

| ส่วน | ความหมาย |
|------|----------|
| รายได้ที่ชำระแล้ว | ผลรวม `orders.total_amount` ที่ `payment_status = paid` ตาม `paid_at` ใต้การ์ดแสดงค่าธรรมเนียมที่เก็บจากลูกค้า (`payments.fee_amount` ของรายการที่ชำระแล้ว) แยกไว้ ไม่รวมในยอดนี้ |
| รอตรวจสอบ / รอชำระ | ยอดออเดอร์ตามสถานะชำระในช่วงที่เลือก |
| ยอดสินค้า / ค่าส่ง / ส่วนลด | จากออเดอร์ที่ชำระแล้ว |
| ตามวิธีชำระ | รวมจากตาราง `payments` ที่ status = paid แยก โอนเงิน / QR พร้อมเพย์ / บัตรเครดิต / เก็บเงินปลายทาง ยอดนี้รวมค่าธรรมเนียมที่ลูกค้าจ่ายแล้ว |
| ใบเสร็จรับเงิน | รายการที่ชำระแล้วมีปุ่ม "ใบเสร็จ" (เปิด PDF) และ "PDF" (ดาวน์โหลด) ดู `docs/receipts.md` |
| รายการชำระเงิน | ยอดแต่ละรายการรวมค่าธรรมเนียม และแสดง "รวมค่าธรรมเนียม ฿..." เมื่อมี ตั้งค่าค่าธรรมเนียมดู `docs/payments.md` |
| ตามประเภทสินค้า | หนังสือ / วิชา / ข้อสอบ จาก `order_items` |
| ตามสถานะชำระ | จำนวน + ยอดออเดอร์ที่สร้างในช่วง |
| รายได้รายวัน | group by วันที่ชำระ |
| รอตรวจสอบล่าสุด | รายการที่ต้องยืนยันการโอน |
| ออเดอร์ชำระแล้วล่าสุด | 15 รายการล่าสุดในช่วง |

## ตัวกรองช่วงเวลา

- ปุ่มลัด: วันนี้ / 7 วัน / เดือนนี้ / ปีนี้
- หรือเลือก `from` – `to` เอง (ค่าเริ่มต้น = เดือนปัจจุบัน)
