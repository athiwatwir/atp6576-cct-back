# ใบเสร็จรับเงิน (Receipts)

ระบบออกใบเสร็จรับเงิน 1 ใบต่อออเดอร์ เมื่อออเดอร์ชำระสำเร็จ แล้วสร้างไฟล์ PDF (ภาษาไทย ฟอนต์ Garuda ผ่าน [mPDF](https://mpdf.github.io/)) จากข้อมูลที่บันทึกไว้

## ออกเมื่อไร

| ช่องทางชำระ | ออกใบเสร็จ | ส่งอีเมลพร้อม PDF |
|------|------|------|
| QR พร้อมเพย์ / บัตร (gateway) | ตอน gateway ยืนยันชำระ | ใช่ อีเมล "ผลการสั่งซื้อ" แนบ PDF |
| แอดมินอนุมัติสลิปในหน้าการเงิน | ตอนเปลี่ยนเป็นชำระแล้ว | ใช่ |
| ออเดอร์ยอด 0 บาท | ตอนสร้างออเดอร์ | ใช่ |
| แอดมินบันทึกชำระในหน้านักเรียน | ตอนบันทึก | ใช่ (อีเมลเดิมของขั้นตอนนี้ แนบ PDF เพิ่ม) |
| ออเดอร์ที่ชำระก่อนมีระบบใบเสร็จ | ตอนเปิด/ดาวน์โหลดครั้งแรก หรือเมื่อ API ส่งออเดอร์นั้น | ไม่ส่งย้อนหลัง |

ออกซ้ำไม่ได้ เรียกออกอีกครั้งได้ใบเดิม ถ้าสร้าง PDF ไม่สำเร็จ อีเมลยืนยันยังส่งโดยไม่มีไฟล์แนบ และบันทึก error ใน log

## เลขที่ใบเสร็จ

`RC{ปีเดือน}{ลำดับ 4 หลัก}` เช่น `RC26100001` นับต่อกันทั้งเดือนตามวันที่ชำระ ใช้ `document_sequences` ประเภท `receipt` (ดู `docs/document-sequences.md`)

## ข้อมูลที่เก็บ (`receipts`)

ใบเสร็จเก็บสำเนาข้อมูล ณ วันชำระ แก้ชื่อสินค้า ราคา หรือข้อมูลลูกค้าภายหลังไม่ทำให้ใบเสร็จเปลี่ยน

| คอลัมน์ | ความหมาย |
|------|------|
| `receipt_no` | เลขที่ใบเสร็จ (unique) |
| `order_id` | ออเดอร์ (1 ใบต่อออเดอร์) |
| `payment_id` | รายการชำระที่สำเร็จ |
| `issued_at` | วันที่ชำระ (`orders.paid_at`) |
| `customer_name`, `customer_email`, `customer_phone`, `customer_address` | ผู้ชำระ ที่อยู่ใช้ที่อยู่จัดส่งถ้าเป็นหนังสือ ไม่เช่นนั้นใช้ที่อยู่ในโปรไฟล์ |
| `payment_method`, `payment_reference` | วิธีชำระ และเลขอ้างอิง (charge id ของ gateway หรือเลขอ้างอิงของเรา) |
| `items` | รายการ (ชื่อ จำนวน ราคาต่อหน่วย รวม) |
| `subtotal`, `discount_amount`, `shipping_amount`, `fee_amount`, `total_amount` | ยอด `total_amount` = ยอดออเดอร์ + ค่าธรรมเนียมชำระเงิน |

## เนื้อหาใน PDF

หัวกระดาษผู้ออก (โลโก้ ชื่อ ที่อยู่ เลขประจำตัวผู้เสียภาษี โทร อีเมล) เลขที่ วันที่ (เวลาไทย พ.ศ.) เลขคำสั่งซื้อ ผู้ชำระ ตารางรายการ ยอดรวม ส่วนลด ค่าจัดส่ง ค่าธรรมเนียม ยอดชำระทั้งสิ้น จำนวนเงินเป็นตัวอักษร วิธีชำระ และเลขอ้างอิงการชำระ

เอกสารนี้เป็น **ใบเสร็จรับเงิน** ไม่ใช่ใบกำกับภาษี ถ้าบริษัทจดทะเบียน VAT และต้องออกใบกำกับภาษีเต็มรูป ต้องเพิ่มการแยกภาษีมูลค่าเพิ่มและข้อมูลผู้ซื้อตามกฎหมาย

## ตั้งค่า `.env`

```env
RECEIPT_COMPANY_NAME="Click Class Tutor"      # ไม่ตั้งใช้ APP_NAME
RECEIPT_COMPANY_ADDRESS="..."
RECEIPT_TAX_ID=
RECEIPT_PHONE=
RECEIPT_EMAIL=                                # ไม่ตั้งใช้ MAIL_SUPPORT_ADDRESS
RECEIPT_LOGO=images/logo/logo.png             # path ใน public/ เว้นว่าง = ไม่มีโลโก้
RECEIPT_NOTE="ใบเสร็จนี้ออกโดยระบบอัตโนมัติ ใช้เป็นหลักฐานการชำระเงิน"
RECEIPT_TIMEZONE=Asia/Bangkok
RECEIPT_DOWNLOAD_TTL_MINUTES=60               # อายุลิงก์ download_url ใน API
```

ค่าเหล่านี้อ่านตอนสร้าง PDF ใบเสร็จที่ออกแล้วจะแสดงหัวกระดาษตามค่าปัจจุบัน ไฟล์ชั่วคราวของ mPDF อยู่ที่ `storage/app/mpdf` (ต้องเขียนได้)

## หน้าแอดมิน

- **การเงิน** (`/finance`) รายการที่ชำระแล้วมีปุ่ม "ใบเสร็จ" (เปิดในแท็บใหม่) และ "PDF" (ดาวน์โหลด)
- **หน้าออเดอร์** ส่วนการชำระเงินแสดงเลขที่ใบเสร็จ ปุ่มเปิด และดาวน์โหลด PDF
- Route: `GET /orders/{order}/receipt` (`orders.receipt`) ใส่ `?inline=1` เพื่อเปิดในเบราว์เซอร์ ออเดอร์ที่ยังไม่ชำระตอบ 404

## API

ดู `docs/student-api.md` หัวข้อใบเสร็จรับเงิน

| Endpoint | ใช้กับ |
|------|------|
| `GET /api/v1/orders/{id}/receipt` | นักเรียนที่ล็อกอิน (เฉพาะออเดอร์ของตัวเอง) |
| `GET /api/v1/guest/orders/{guest_token}/receipt` | ผู้ซื้อแบบไม่สมัครสมาชิก |
| `receipt.download_url` ใน `OrderResource` | ลิงก์ signed เปิดได้โดยไม่ต้องแนบ token หมดอายุตาม `RECEIPT_DOWNLOAD_TTL_MINUTES` (`GET /receipts/{receipt}/download`) |
