# โปรโมชัน

หน้าแอดมิน `/promotions` (`PromotionController`, `resources/views/pages/promotions/_form.blade.php`)

## เงื่อนไขที่ตั้งได้

| ฟิลด์ในฟอร์ม | เก็บที่ |
|------|------|
| กลุ่มนักเรียน (ทุกคน / นักเรียนใหม่ / นักเรียนเก่า) | `promotions.rules.student_group` |
| ต้องเคยซื้อวิชา / หนังสือ | `promotion_required_courses`, `promotion_required_products` |
| ต้องดูวิดีโอก่อนใช้โปรโมชัน | `promotion_required_videos` |
| ต้องดูอย่างน้อย (วินาที) | `promotions.rules.required_video_seconds` |
| ซื้อวิชานี้ / แถมข้อสอบ / แถมหนังสือ | `promotion_gift_courses`, `promotion_gift_assessments`, `promotion_gift_products` |
| สินค้าที่ใช้ส่วนลดได้ | `promotion_courses`, `promotion_curriculums`, `promotion_assessments`, `promotion_products` (`rules.applies_to` = `selected` หรือ `all`) |

### ต้องดูวิดีโออย่างน้อยกี่วินาที

- ใช้ค่าเดียวกับทุกวิดีโอที่เลือกในช่อง "ต้องดูวิดีโอก่อนใช้โปรโมชัน"
- เว้นว่าง (`null`) หมายถึงต้องดูจนจบ ใส่ได้ 1–86,400 วินาที
- ต้องเลือกวิดีโออย่างน้อย 1 รายการจึงกำหนดได้ ถ้าไม่เลือกวิดีโอ ระบบเก็บเป็น `null`
- ต้องไม่เกินความยาวของวิดีโอที่เลือก (ตรวจเฉพาะวิดีโอที่มี `duration_seconds` มากกว่า 0) รายการวิดีโอในฟอร์มแสดงความยาวต่อท้ายชื่อ
- หน้ารายการและหน้ารายละเอียดแสดงเป็นข้อความ เช่น "ต้องดู บทที่ 1 อย่างน้อย 2 นาที ก่อน" หรือ "ต้องดู บทที่ 1 จนจบ ก่อน" (`Promotion::requiredVideoLabel()`, `Promotion::requiredVideoSeconds()`)

## ข้อจำกัดปัจจุบัน

เงื่อนไขในหัวข้อข้างบน (กลุ่มนักเรียน ต้องเคยซื้อ ต้องดูวิดีโอและจำนวนวินาที ของแถม) เก็บและแสดงในหลังบ้านเท่านั้น ระบบยังไม่ตรวจหรือใช้ตอนคิดยอดคูปอง (`CouponService`) หรือสร้างออเดอร์ และ API นักเรียนยังไม่ส่งข้อมูลโปรโมชัน

ความคืบหน้าวิดีโอของนักเรียนเก็บใน `video_progress` (`position_seconds` คือตำแหน่งล่าสุดที่เล่น ไม่ใช่ตำแหน่งไกลสุดที่เคยดู และ `completed_at` ตั้งเมื่อดูถึง 90%) ถ้าจะบังคับเงื่อนไข "ดูอย่างน้อย N วินาที" ควรเก็บตำแหน่งไกลสุดหรือเวลาที่ดูจริงเพิ่ม เพราะนักเรียนเลื่อนกลับแล้ว `position_seconds` จะลดลง
