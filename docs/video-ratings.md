# คำแนะนำ/ติชม (คะแนนวิดีโอ)

นักเรียนให้ดาว 1–5 และคำแนะนำกับวิดีโอผ่าน `PUT /courses/{slug}/videos/{video}/rating` (ดู `docs/student-api.md`) เก็บที่ตาราง `video_ratings` คนละหนึ่งรายการต่อวิดีโอ เรียกซ้ำเป็นการแก้ไข

## หน้าแอดมิน

เมนู "คำแนะนำ/ติชม" ในกลุ่มภาพรวม ต่อจาก Activity Log เส้นทาง `/video-ratings` (`VideoRatingController@index`, `resources/views/pages/video-ratings/index.blade.php`) ดูอย่างเดียว ไม่มีแก้ไขหรือลบ

การ์ดสรุปด้านบนคิดจากตัวกรองปัจจุบัน (ยกเว้นตัวกรองคะแนน)

- คำติชมทั้งหมด คะแนนเฉลี่ย จำนวนที่มีข้อความ และจำนวนคะแนนต่ำ (1–2 ดาว)
- แถบคะแนน 5 ถึง 1 ดาว แสดงจำนวนต่อดาว กดเพื่อกรองคะแนนนั้น กดซ้ำเพื่อยกเลิก

ตารางแสดง 20 รายการต่อหน้า

| คอลัมน์ | ข้อมูล |
|------|------|
| วันที่ | เวลาแก้ไขล่าสุด (`updated_at`) เวลาไทย ถ้าเคยแก้ไขแสดงวันที่ให้คะแนนครั้งแรกด้วย |
| นักเรียน | ชื่อ (ลิงก์ไปหน้านักเรียน) อีเมล เบอร์โทร |
| วิชา / วิดีโอ | รหัสและชื่อวิชา (ลิงก์ไปหน้าวิชา) ชื่อบทที่วิดีโออยู่ในวิชานั้น และชื่อวิดีโอ |
| คะแนน | ดาว 1–5 |
| คำแนะนำ | ข้อความเต็ม คงการขึ้นบรรทัดใหม่ |

## ตัวกรอง

| ตัวกรอง | query | หมายเหตุ |
|------|------|------|
| ค้นหา | `search` | ชื่อ อีเมล เบอร์โทรนักเรียน ชื่อวิดีโอ หรือข้อความ |
| วิชา | `course_id` | แสดงเฉพาะวิชาที่มีคำติชม เปลี่ยนแล้วกรองทันที |
| วิดีโอ | `video_id` | เลือกได้หลังเลือกวิชา แสดงเฉพาะวิดีโอที่มีคำติชมในวิชานั้น |
| คะแนน | `rating` | 1–5 |
| ข้อความแนะนำ | `comment` | `with` มีข้อความ, `without` ให้แค่ดาว |
| ช่วงวันที่ | `from`, `to` | `Y-m-d` เวลาไทย เทียบกับ `updated_at` มีปุ่มลัด วันนี้ / 7 วัน / 30 วัน / ทั้งหมด |
| เรียงตาม | `sort` | `latest` (ค่าเริ่มต้น), `oldest`, `rating_desc`, `rating_asc` |

ค่าที่ไม่ถูกต้องถูกละเว้น ปุ่ม "ล้าง" คืนค่าเริ่มต้นทั้งหมด
